02 · MQTT ThingsBoard / Mastify

MQTT menggunakan TLS dan ThingsBoard-compatible token sebagai username. Token tidak ditampilkan kembali.

Topic publish tetap v1/devices/me/telemetry. Subscribe atribut dan RPC bersifat read-only. Relay tidak bisa diaktifkan melalui web atau MQTT.

MQTT 2 · Mastify Asri (Opsional)

Koneksi tambahan, tidak menggantikan MQTT ThingsBoard. Port Mastify saat ini menggunakan MQTT biasa (tanpa TLS); gunakan hanya pada jaringan uji tepercaya. Simpan konfigurasi akan me-restart ESP32-S3.

Device: TA-GMS-DEV-01 · Topic: v1/devices/me/telemetry. Payload menggunakan ts + values (schema Asri). Data level dalam persen tidak dikirim sebagai mm; data EWIG tidak dipetakan sebelum validasi.

04 — Konfigurasi Tangki (HDL300 A2)

Isi ukuran bagian dalam tangki. Nilai level ke Mastify selalu milimeter; persentase dihitung dari tinggi tangki; liter dihitung untuk tangki kotak/persegi panjang.

PENTING: jangan aktifkan kalibrasi dua titik jika pembacaan mA di titik nol dan referensi belum stabil dan berulang. Ukuran P/L/T tidak mengubah rentang fisik HDL300 0–5 m.

04 · Kalibrasi & Ambang Batas Sensor

Sesuaikan rentang pembacaan 4–20 mA, nilai keluaran, dan batas peringatan masing-masing sensor. Konfigurasi disimpan ke NVS tanpa restart.

Mode Bench Test: Fitur ini mengatur scaling sensor dan indikator peringatan. Tidak mengaktifkan relay atau shutdown otomatis. Nilai threshold harus mengikuti spesifikasi sensor dan kebutuhan operasional mesin.

Temperature · A0

Sensor suhu melalui ADS1115 kanal A0. Satuan keluaran: °C.

Level · A2

Sensor level melalui ADS1115 kanal A2. Satuan keluaran: %.

Pressure · A3

Sensor tekanan melalui ADS1115 kanal A3. Satuan keluaran: bar.

Simulasi Arus Sensor (A0 / A2 / A3) — BENCH TEST

SIMULASI ON: satu sensor dipilih dan nilai mA virtual dipakai pada dashboard dan MQTT. Dua sensor lainnya tetap REAL. SIMULASI OFF: semua kembali REAL pada siklus telemetri berikutnya. Sensor fisik tetap dibaca. Maksimum 120 detik.

Hanya untuk perangkat uji: jangan sambungkan alarm simulasi ke relay, proteksi, atau insiden produksi.

Mode uji nonaktif saat ESP32 restart. Nilai data tes akan selalu ditandai dalam telemetri.

Informasi & Batasan

Sensor: A0 suhu; A2 level; A3 tekanan. EWIG: UART1 TX15/RX16/RTS14, 9600 8N1, slave 1. 56 Ω per loop. Data MQTT tetap dikirim dari firmware secara langsung. Paket bench test ini belum memiliki OTA, persistent offline queue, validasi metrologis sensor, ataupun driver relay untuk proteksi mesin.

Hati-hati: perubahan IP statis yang salah dapat memutus akses Wi-Fi kantor. Gunakan IP AP 192.168.4.1 untuk pemulihan.
